One line about office life, written to be judged head-to-head against the
field: the fire drill, the only meeting this quarter where everyone arrived
on time, left early, and nobody asked to circle back. A deterministic
Python program writes the joke to `entry.txt` — no network, no randomness,
no clock reads — so every run produces the same single line. See
`candidates.md` for the variants tested and why this one was kept.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```
